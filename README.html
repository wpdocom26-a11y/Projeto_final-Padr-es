🌟 Missão dos Agrupamentos

Aplicação Educacional de Pensamento Computacional e Classificação Lógica
Público: 1º Ano do Ensino Fundamental BNCC Computação: EF01CO01 Web Estática: GitHub Pages Acessibilidade: Web Speech API

1. Visão Geral e Fundamentação Pedagógica

Missão dos Agrupamentos é um software educativo interativo desenvolvido especificamente para crianças de 6 a 7 anos (em fase inicial de alfabetização). A aplicação foca na construção das bases do pensamento computacional através do reconhecimento de atributos (cor, forma, categoria de uso) e da compreensão de que um mesmo conjunto de dados/objetos pode ser classificado sob diferentes critérios.

🎯 Habilidade BNCC EF01CO01: "Reconhecer que os objetos podem ser agrupados de diferentes maneiras a partir de características comuns (como cor, forma, tamanho, textura, categoria/uso etc.) e descrever as características de cada agrupamento."

2. As 5 Missões Educativas

🎨 1. Cores
📐 2. Formas
📦 3. Categorias
🔍 4. Regra Secreta
⭐ 5. Meu Grupo
Missão Mecânica & Desafio Objetivo de Aprendizagem
Missão 1: Cores Grid com 6 objetos; selecionar todos os itens de cor amarela (banana, sol, patinho). Isolamento do atributo de cor, ignorando forma e categoria.
Missão 2: Formas Grid com 6 objetos; selecionar itens com contorno redondo (moeda, relógio, botão). Reconhecimento de padrões geométricos em objetos do cotidiano.
Missão 3: Categorias Grid com 6 objetos; colocar no baú apenas as figuras de animais vivos. Abstração semântica e classificação por função/natureza biológica.
Missão 4: Regra Secreta Analisar um grupo pré-montado e deduzir a regra comum ("Todos são vermelhos"). Raciocínio indutivo e descoberta de padrões em conjuntos de dados.
Missão Final: Meu Grupo A criança escolhe a sua própria regra e seleciona os objetos compatíveis. Autonomia, flexibilidade cognitiva e consolidação da tese central.
💡 "Os mesmos objetos podem formar grupos completamente diferentes dependendo da característica que observamos!"

3. Diretrizes de Mediação & Feedback Formativo

  • Feedback de Sucesso: Comemoração imediata acompanhada de explicação verbal e textual da característica comum do grupo.
  • Feedback Formativo (Sem Punição): O sistema nunca exibe mensagens secas de "errado" ou penalidades. Ele fornece dicas acolhedoras de observação orientada.
  • Andaime Pedagógico (Scaffolding): Na 2ª tentativa com dúvida, um brilho suave é ativado nos itens pertinentes para apoiar a criança sem frustração.

4. Acessibilidade e Usabilidade Infantil

  • Locução por Síntese de Voz: Integração nativa com a Web Speech API em português (pt-BR) para leitura em áudio das instruções e dicas.
  • Alvos de Toque Confortáveis: Botões e cartões com dimensões $\ge 56\text{px}$ com espaçamento seguro para toques em tablets e smartphones.
  • Ilustrações Vetoriais SVG: Ícones nítidos em qualquer resolução e de carregamento instantâneo.
  • Privacidade Total (LGPD Infantil): Sem necessidade de login, senhas ou armazenamento de dados pessoais.

5. Arquitetura e Execução Técnica

A aplicação foi projetada para ser 100% estática, sem backend e sem banco de dados, pronta para o GitHub Pages.

Projeto-final/
├── index.html        # Estrutura semântica SPA (Telas Inicial, Missões e Conclusão)
├── css/
│   └── style.css     # Estilização responsiva, CSS Grid, variáveis e temas infantis
├── js/
│   ├── data.js       # Catálogo de objetos com SVGs e configurações das 5 missões
│   └── app.js        # Estado reativo, validação formativa e Web Speech API
└── README.md         # Documentação técnica e pedagógica

Como Executar Localmente:

  1. Abra o arquivo index.html em qualquer navegador moderno (Chrome, Edge, Firefox, Safari).
  2. Ou execute via terminal com Python: python -m http.server 8000 e acesse http://localhost:8000.

Como Publicar no GitHub Pages:

  1. Envie os arquivos para o repositório no GitHub (git push origin main).
  2. Acesse Settings > Pages no repositório.
  3. Em Source, selecione a branch main e pasta / (root) e clique em Save.
